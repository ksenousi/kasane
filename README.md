# Kasane 重ね

A touch-only JLPT N3 vocab and grammar trainer for iPhone, with WaniKani-style spaced repetition and levels.

Built as an installable web app (PWA): open it in Safari, then Share → Add to Home Screen.

**Live app:** https://ksenousi.github.io/kasane/
